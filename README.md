# 你的第一个幻灯片 Skill

年终述职、工作汇报、项目复盘，最费时间的往往是从一堆截图、表格、聊天记录里理出“我到底要说什么”。

这个 Skill 让 AI 替你做这一步：你把手上的材料放进一个文件夹，跟它说一句要做什么，它读完材料，挑出最能说明问题的几个数，排成一套能直接讲的幻灯片。

> **Skill 是什么？** 一份写给 AI 的说明。它告诉 AI 这类事情怎么做、哪里容易出错、做完怎么检查，AI 每次动手前都会先读它。

## 做出来的是什么

- 一个网页文件，双击就能打开，不联网也能放。
- 按 → 或空格一步一步往下讲，数字跟着你讲的节奏出来。
- 每页都有写好的讲稿（按 N 看）；投影的时候按 D 多开一个讲者窗口，讲稿只在你这边。
- 标了出处的数，有人问，按 S 就能看到它从哪份材料来、怎么算的。

## 怎么开始

### ① 准备一个能动手的 AI 工具

Skill 要装在能读写你电脑上的文件、能自己运行工具的 AI 里。视频里用的是 WorkBuddy。只能在对话框里聊天的 AI，跑不了这个 Skill。

### ② 让它帮你装好

把下面这段话复制给它：

```text
帮我装一个做幻灯片的 Skill，链接在这：
https://github.com/eric4umd/first-slides-skill
你先读一下里面的说明，再把它装到你放 Skill 的地方。
看看我这台电脑缺不缺东西，缺的话你来装；要装软件、或者要我点什么之前，先跟我说一声。
装好以后用里面的示例做一份试试，能打开就告诉我。
我电脑上原来的东西别动。
```

看过视频的，也可以把视频里装 Skill 那一屏截图发给它，说一句“照这张图做”。

### ③ 做你的第一套

把材料放进一个文件夹：截图、导出的表格、聊天记录、备忘录、去年的稿子都行，不用先整理。然后跟它说一句，比如：

```text
我把今年的材料都放在桌面的「年终述职材料」文件夹里了，有群里的截图、后台数据、我的备忘录，还有去年的述职大纲。
帮我用这些做一套年终述职的幻灯片，下周五讲给主管和老板听，二十分钟左右。
拿不准的地方先空着，做完一起问我。
```

把场合、听的人、时长换成你自己的。

### ④ 打开，讲一遍，哪里不顺就告诉它

双击打开，按 F 全屏，从头讲一遍。哪一页不顺，直接说是第几页、哪里不对、想改成什么样，比如：

```text
第 2 页的标题太长了，我一眼看不完，帮我改短一点，意思别变。
```

## 讲的时候

| 按键 | 做什么 |
|---|---|
| → 或空格 | 往下讲一步 |
| ← | 往回 |
| F | 全屏，再按一次退出 |
| N | 看这一页的讲稿，再按一次收起（显示在幻灯片上，自己练的时候用） |
| D | 多开一个讲者窗口：讲稿、下一页、计时都在里面。投影或共享屏幕时，只放原来那个窗口 |
| S | 看标了出处的数从哪来 |
| B | 黑屏，再按一次回来 |
